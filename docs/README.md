# Documentation map

- [Project README](../README.md): current setup, feature status, limits and test commands.
- [Architecture](architecture.md): current runtime boundaries and persistence.
- [API](api.md): route overview; `/docs` on a running backend is the canonical schema.

- [Practical difficulty](practical-interview-difficulty.md): current generation policy and its development verification.

- [Tooling](../scripts/README.md): offline checks versus data-bound/paid historical operators.

Phase-numbered reports are historical evidence, not a claim that every earlier
threshold or difficulty definition is current. The practical difficulty report
supersedes the former insistence on multi-constraint Hard questions. Prior labels
and evaluation outputs were not rewritten.

Many reports reference `storage/` screenshots, vectors, backups and raw receipts.
Those artifacts can include private data and remain local. Their links are not
public downloads; this repository contains the reports and reviewed source, not
the private development environment. Older privacy/evaluation notes may be less
complete than the current README and should not be treated as deployment promises.
